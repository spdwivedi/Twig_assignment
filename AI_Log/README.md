# AI Interaction & System Trace Logs

This directory contains the unabridged, full-fidelity interaction records and prompt logs for the **Twig Data Engineering Project**.

---

## 1. Directory Contents

- **`AI_Interaction_Log.md`**:
  - The comprehensive chronological record of engineering decisions, phase progressions, prompt specifications, code generation traces, and user review milestones.
  - Documents how each architectural component—from polite web scrapers and Pydantic schemas to DSU graph deduplication and multi-model LLM rate cards—was designed, implemented, and verified.

---

## 2. Retention Policy

- All AI interaction logs, model prompts, and conversational telemetry are preserved exclusively within this `AI_Log/` folder to keep the project root clean and properly categorized.
- In accordance with repository guidelines, no AI log files are kept in the root directory.
